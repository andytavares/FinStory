# Money user guide

Money is a Mac app that reads your bank, card and payment-app transactions and sorts each one into a category. You do not type in transactions. Money then finds your recurring charges, warns you about unusual spending, and writes a weekly digest and a monthly report. Everything stays on your Mac, encrypted. Money reads and reports. It never moves money.
